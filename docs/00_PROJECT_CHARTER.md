# 项目章程

## 项目定位

Vision Research Lab 是一个长期维护的计算机视觉研究仓库。它服务于算法学习、实验复现和 AI 岗作品集，不承担复杂前端、后端或产品账号体系。

## 为什么选择这个项目

过去的练习已经覆盖单图推理、批量预测、CNN 训练、优化器与学习率比较、模型保存和混淆矩阵。下一阶段的核心提升不是继续增加彼此独立的脚本，而是建立研究问题、数据流、模块边界、实验追踪和可信评测。

## 成功标准

项目达到第一版可公开状态时，应满足：

- 新环境能够按 README 完成安装和一次小规模训练。
- 同一配置和随机种子能得到可解释的近似结果。
- 至少包含两个基线模型和三个研究改进。
- 每项核心结论至少由三次独立运行支持。
- 同时报告准确率、参数量、推理成本、校准误差和鲁棒性结果。
- 包含消融实验、失败案例与限制说明。
- 不上传数据集、私有路径、大型权重和临时日志。

## 范围内

- 图像分类及其通用训练流程
- CNN 和残差网络
- 数据增强、正则化与损失函数
- 分布偏移、噪声和腐蚀鲁棒性
- 置信度校准与不确定性分析
- 知识蒸馏、剪枝、量化和效率比较
- 可复现实验、测试和技术报告

## 暂不纳入

- Web 前端和复杂服务端
- 用户系统、数据库和云平台工程
- 从零训练大型视觉 Transformer
- 大规模多机训练
- 为追求功能数量而同时开展分类、检测、分割和生成

## 目标岗位能力映射

| 项目部分 | 对应能力 |
|---|---|
| 数据与划分 | 数据治理、避免泄漏、可复现性 |
| 基线训练 | PyTorch、训练循环、优化与调参 |
| 统一评测 | 指标设计、错误分析、实验公平性 |
| 鲁棒性 | 分布偏移、模型泛化、可靠性 |
| 校准 | 概率解释、不确定性、风险意识 |
| 压缩 | 部署约束、速度与精度权衡 |
| 测试与文档 | 工程质量、协作和研究表达 |
