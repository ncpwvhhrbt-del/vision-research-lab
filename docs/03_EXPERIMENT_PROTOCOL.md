# 实验协议

## 数据协议

- 首期使用 CIFAR-10。
- 训练集进一步固定划分训练与验证部分。
- 测试集只用于最终报告，不参与超参数选择。
- 数据划分索引需要保存，以便所有模型使用同一划分。
- 归一化统计只来自训练数据或采用数据集公开标准。

## 基线协议

第一批基线：

1. 现有练习级简单 CNN 的规范化重建版
2. ResNet-18
3. 一个参数量更小的轻量 CNN

基线之间应统一数据、epoch 和评测方法；同时允许记录各模型达到最佳验证性能所需时间。

## 重复实验

- 快速开发：固定单一随机种子。
- 正式结论：至少 3 个随机种子。
- 报告均值、标准差和单次最佳结果。
- 不用反复挑选随机种子来制造更好结果。

## 指标

### 预测性能

- Top-1 Accuracy
- Macro Precision、Recall、F1
- 每类别准确率
- 混淆矩阵

### 可信度

- Negative Log-Likelihood
- Brier Score
- Expected Calibration Error
- 高置信错误数量

### 鲁棒性

- 各类扰动和强度下的准确率
- 相对干净测试集的性能下降
- 类别级鲁棒性差异

### 效率

- 参数量
- 模型文件大小
- 峰值显存
- 单批次延迟和吞吐量
- 训练时间

## 实验记录最低字段

- 实验 ID 与简短名称
- Git commit
- 配置文件
- 数据版本或划分标识
- 随机种子
- 硬件与软件环境
- 最佳 epoch 和选择依据
- 训练、验证、测试指标
- 权重路径和输出文件
- 结论、异常和失败说明

## 消融实验规则

- 一次优先改变一个因素。
- 组合方法需要对应单独方法作为对照。
- 所有对比应给出训练预算差异。
- 负结果保留并解释，不从历史中删除。

## 防止常见错误

- 测试集参与调参。
- 模型结构改变后加载旧权重却不校验。
- 训练和评测使用不同归一化。
- 最后一批样本被错误忽略。
- 只保存图片，不保存生成图片的原始指标。
- 仅凭训练 loss 判断模型有效。
