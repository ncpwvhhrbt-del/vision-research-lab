# 开发路线图

## Phase 0：研究与仓库设计

- [x] 项目定位和边界
- [x] 目录结构
- [x] 研究问题
- [x] 实验协议
- [x] GitHub 作品集标准

退出条件：无需代码即可清楚回答“研究什么、怎么比较、如何证明”。

## Phase 1：最小可复现基线

- [ ] 定义 Python 环境和依赖
- [ ] 建立配置读取方式
- [ ] CIFAR-10 数据模块
- [ ] 简单 CNN 与 ResNet-18
- [ ] 训练、验证、checkpoint
- [ ] 统一评测和一次冒烟测试

退出条件：一个命令完成小规模训练，结果可追溯到配置。

## Phase 2：基线研究

- [ ] 固定数据划分和随机种子组
- [ ] 优化器比较
- [ ] 学习率策略比较
- [ ] 数据增强比较
- [ ] 损失函数和正则化比较
- [ ] 首份基线报告

退出条件：产生公平的基线排行榜和可解释结论。

## Phase 3：鲁棒性与校准（已完成）

- [x] 构建图像扰动评测集
- [x] 鲁棒性曲线数据
- [x] ECE、可靠性图
- [x] Brier Score
- [x] 温度缩放
- [x] 高置信错误案例集

退出条件：项目从“准确率竞赛”升级为模型可靠性研究。已完成。

## Phase 4：高效模型

- [ ] 教师模型与学生模型
- [ ] 知识蒸馏
- [ ] 剪枝或量化
- [ ] 延迟、吞吐量和显存测试
- [ ] 精度-效率 Pareto 图

退出条件：形成可面试讲解的模型压缩研究闭环。

## Phase 5：迁移任务

- [ ] CIFAR-100
- [ ] Tiny-ImageNet 子集或通用异常检测数据
- [ ] 验证核心结论是否跨数据集成立
- [ ] 发布 v1.0 技术报告

退出条件：证明方法不是只对一个数据集有效。

## 学习方式

每个 Phase 都采用短检查点：先明确函数责任和张量流，再逐个实现、测试和提交。每次只推进一个可验证模块。
